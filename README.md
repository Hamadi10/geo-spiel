# 🌍 Geo-Spiel

Ein Geografie-Spiel mit 3D-Globus – Länder, Flaggen, Hauptstädte, Regionen und Meere.
Vier Sprachen (Deutsch, English, Français, العربية), Lern- und Profi-Modus, Mehrspieler.

**Spielen:** https://hamadi10.github.io/geo-spiel/

Daten: Natural Earth (Karten), flag-icons (Flaggen), world-countries (Länder-Infos), GeoNames (Städte).
